# 🎴 AI Flashcard Generator & Quiz

An AI-powered **Flashcard Generator and Quiz application** built with Python.
It automatically generates study flashcards and quiz questions from a given topic using an AI model.

## 🚀 Features

* 🎴 Generate AI-powered flashcards
* 📝 Create quiz questions for practice
* 📚 Enter any topic for learning
* 🔢 Choose the number of flashcards
* ⚡ Fast AI-generated content
* 🎯 Useful for students and exam preparation
* 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **OpenAI API**
* **Hugging Face**
* **python-dotenv**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/flashcard-generator.git
```

### 2. Open the project folder

```bash
cd flashcard-generator
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pi
```
